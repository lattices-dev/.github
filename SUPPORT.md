# Support

Start with the [docs](https://lattices.dev/docs/quickstart) and [agent API](https://lattices.dev/docs/api). The [site](https://lattices.dev) links to Lattices, Action, Speech and Blink.

For a reproducible bug or feature request, open an issue in the affected repository. Include the product, version, macOS version, and steps to reproduce. Remove secrets and private screen content from logs and screenshots.

Report vulnerabilities privately through the repository's Security tab, following its security policy.
